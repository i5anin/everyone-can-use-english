# 1. Звуки и транскрипция

В живой речи неделимые далее составные части называются **фонемами**, или звуками (*phonemes*).

Звуки английского делятся на **гласные** (*vowels*) и **согласные** (*consonants*). **Транскрипция** (*phonetics*) — система знаков для обозначения звуков: каждый звук обозначается своим особым знаком.

Мы пользуемся системой транскрипции «Кембриджского словаря английского произношения» ([Cambridge English Pronouncing Dictionary](https://dictionary.cambridge.org/pronunciation/), i.e. *CEPD*).

В «Кембриджском словаре английского произношения» британский английский записан транскрипцией *D.J.* (Дэниела Джонса), а американский — Международным фонетическим алфавитом (*IPA*)[^1], с некоторыми «улучшениями» под американский английский:

> * у <span class="pho">ə</span> есть краткий и долгий варианты с «r»-окраской: <span class="pho">ɚ</span> и <span class="pho">ɝː</span>
> * в дифтонгах и трифтонгах, кончающихся на <span class="pho">ə</span>, конечный <span class="pho">ə</span> заменён на <span class="pho">r</span>, например <span class="pho">ɪə</span>  ⭢ <span class="pho">ɪr</span> или <span class="pho">aʊə</span>  ⭢ <span class="pho">aʊr</span>
> * краткая гласная <span class="pho">ɒ</span> обозначается как <span class="pho">ɑː</span>
> * у <span class="pho">t</span> добавлен вариант с одним ударом языка <span class="pho">t̬</span>

Список ниже отчасти основан на официальном указателе знаков транскрипции [«Кембриджского словаря английского произношения»](https://dictionary.cambridge.org/pronunciation/); мы его дополнили и переупорядочили[^2], а число примеров намеренно сократили.

> [!Note]
> Официальный указатель знаков транскрипции «Кембриджского словаря английского произношения» (Pronunciation symbols):
> > https://dictionary.cambridge.org/help/phonetics.html

Хотя наш курс посвящён звукам «**американского английского**», для удобства обучения приведены и звуки и знаки «британского английского».

## 1.5. Собственные дополнительные знаки

| Знак | Значение |
| ------------------------------------------------------ | --------------------------------------------------------------------------- |
| <span class="pho">ɤ</span>                             | гласная ещё легче, чем *schwa* <span class="pho">ə</span>, почти неслышная |
| <span class="pho">ʔ</span>                             | гортанная смычка вместо <span class="pho">t</span> |
| <span class="pho">ᵗ</span>/<span class="pho">◌̥</span>  | можно произнести <span class="pho">t</span> или <span class="pho">t̥</span>, то есть не звучит |
| <span class="pho">◌̚ </span>/<span class="pho">◌̥</span> | знак смычки без взрыва у глухих согласных (равнозначен /<span class="pho">◌̥</span>: оба не звучат) |
| <span class="pho">ᵊ</span>                             | призвук гласной перед слоговыми согласными <span class="pho">l, m, n, r</span> |
| <span class="pho">ʲ</span>                             | вставной звук <span class="pho">j</span> между слогами |
| <span class="pho">ʷ</span>                             | вставной звук <span class="pho">w</span> между слогами |
| <span class="pho">◌̅, ◌́, ◌̀</span>                       | тон слога: ровный, восходящий, нисходящий |
| <span class="pho">◌̂</span>                             | слог с поднятой высотой тона |
| <span class="pho">·</span>                             | остановка между слогами (*stop*) |
| <span class="pho">◌‿◌</span>                           | знак слитного чтения |
| <span class="pho">｜</span>                            | пауза между словами, разделяющая смысловые группы (*pause*) |

> [!Note]
>
> Вы, возможно, заметили, что варианты одного основного звука могут записываться по-разному. Например, основной звук <span class="pho">ɑ</span>: краткая гласная — <span class="pho">ʌ</span>, долгая — не <span class="pho">ʌː</span>, а <span class="pho">ɑː</span>, а в дифтонгах — <span class="pho">a</span>: <span class="pho">aɪ, aʊ</span> и т. д.…
>
> Так сделано потому, что, когда эти звуки стоят рядом, их нельзя неверно сложить и спутать: у каждого звука должен быть свой особый знак[^3].
