<span class="pho">l</span> и <span class="pho">r</span> в начале слога обычно трудностей не вызывают, например *lot* <span class="pho alt">lɑːt</span><span class="speak-word-inline" data-audio-us-male="/audios/lot-us-male.mp3" data-audio-us-female="/audios/lot-us-female.mp3"></span> или *rot* <span class="pho alt">rɑːt</span><span class="speak-word-inline" data-audio-us-male="/audios/rot-us-male.mp3" data-audio-us-female="/audios/rot-us-female.mp3"></span>… Говорящим по-русски нужно помнить лишь одно: американский <span class="pho">r</span> не дрожит — кончик языка ни разу не ударяет по нёбу, он лишь приподнят и отведён назад. Раскатистое русское «р» сразу выдаёт акцент.

## 3.2.12.3. Вставной звук <span class="pho">ᵊ</span>

Трудности с <span class="pho">l</span> всегда возникают, когда он стоит в конце слога.

Попробуйте прочесть *milk* <span class="pho alt">mɪlk</span><span class="speak-word-inline" data-audio-us-male="/audios/milk-us-male.mp3" data-audio-us-female="/audios/milk-us-female.mp3"></span>… Многие на деле говорят <span class="pho alt">mjʊk</span>… Другое частое слово с похожим звучанием тоже часто читают неверно: *build* <span class="pho alt">bɪld</span> <span class="speak-word-inline" data-audio-us-male="/audios/build-us-male.mp3" data-audio-us-female="/audios/build-us-female.mp3"></span> почти всегда звучит как <span class="pho alt">bjʊld</span>. А говорящие по-русски, наоборот, часто смягчают <span class="pho">l</span> и говорят «мильк», «бильд».

У <span class="pho">l</span> в конце слога есть незаметное движение: кончик языка движется вперёд и вверх, пока не прижмётся к альвеолам. Поэтому перед <span class="pho">l</span> в конце слога появляется вставной звук — лёгкий <span class="pho">ᵊ</span>.

По правде говоря, это не так уж трудно: дело нескольких минут.

> * Сначала много раз повторите <span class="pho">ə... əl... ə... əl...</span> Особенно заметьте: открыв рот, губами больше ничего не делайте, **без призвука <span class="pho">ʊ</span> от движения губ**; от <span class="pho">ə</span> к <span class="pho">l</span> связки не перестают колебаться, всё остальное делает кончик языка…
> * затем прямо повторяйте <span class="pho">əl... əl...</span>
> * потом повторяйте <span class="pho">əlk... əlk...</span>
> * а теперь повторяйте <span class="pho">mɪᵊlk... mɪᵊlk...</span>

> [!Note]
> Особенно заметьте две вещи:
> * <span class="pho">ɪ</span> — не просто укороченная <span class="pho">iː</span> ([3.1.3.2](3.1.3-i#_3-1-3-2-краткая-гласная-ɪ)), она ближе к укороченной <span class="pho">eɪ</span>. Так что milk — это <span class="pho alt">mɪlk</span>, а не <span class="pho alt">milk</span>; даже прочесть его как <span class="pho alt">meɪlk</span>, пожалуй, будет точнее — только <span class="pho">eɪ</span> надо постараться сделать покороче<span class="speak-word-inline" data-audio-us-male="/audios/milk-us-male.mp3" data-audio-us-female="/audios/milk-us-female.mp3"></span>…
> * у <span class="pho">l</span> в конце слога кончик языка движется вперёд к альвеолам (положение ③) — это движение очень важно, без него не получится слитное чтение с этим звуком ([4.4.1](4.4-linking#_4-4-1-согласныи-гласная-consonant-vowel)). Многие заменяют это движение звуком <span class="pho">ʊ</span>: например, читают *result* <span class="pho alt">rɪˈzəlt</span> как <span class="pho alt">rɪˈzəʊt</span>, а <span class="pho alt">mɪlk</span> — как <span class="pho alt">mjʊk</span>… Помните: у <span class="pho">l</span> в конце слога работает только кончик языка, **губы не движутся**. Поупражняйтесь так же на *girl* <span class="pho alt">ɡɝːl</span><span class="speak-word-inline" data-audio-us-male="/audios/girl-us-male.mp3" data-audio-us-female="/audios/girl-us-female.mp3"></span> (его часто ошибочно читают как <span class="pho alt">gəʊ</span>) и *world* <span class="pho alt">wɝːld</span><span class="speak-word-inline" data-audio-us-male="/audios/world-us-male.mp3" data-audio-us-female="/audios/world-us-female.mp3"></span> (часто ошибочно — <span class="pho alt">wəʊd</span>).

Частых слов с <span class="pho">l</span> в конце слога много; читая их, не забывайте вставлять <span class="pho">ᵊ</span>, например:

> * *fail* <span class="pho alt">feɪl</span> ⭢ <span class="pho alt">feɪᵊl</span><span class="speak-word-inline" data-audio-us-male="/audios/fail-us-male.mp3" data-audio-us-female="/audios/fail-us-female.mp3"></span>
> * *file* <span class="pho alt">faɪl</span> ⭢ <span class="pho alt">faɪᵊl</span><span class="speak-word-inline" data-audio-us-male="/audios/file-us-male.mp3" data-audio-us-female="/audios/file-us-female.mp3"></span>
> * *sell* <span class="pho alt">sel</span> ⭢ <span class="pho alt">seᵊl</span><span class="speak-word-inline" data-audio-us-male="/audios/sell-us-male.mp3" data-audio-us-female="/audios/sell-us-female.mp3"></span>
> * *sale* <span class="pho alt">seɪl</span> ⭢ <span class="pho alt">seɪᵊl</span><span class="speak-word-inline" data-audio-us-male="/audios/sale-us-male.mp3" data-audio-us-female="/audios/sale-us-female.mp3"></span>
> * *tell* <span class="pho alt">tel</span> ⭢ <span class="pho alt">teᵊl</span><span class="speak-word-inline" data-audio-us-male="/audios/tell-us-male.mp3" data-audio-us-female="/audios/tell-us-female.mp3"></span>
> * *tale* <span class="pho alt">teɪl</span> ⭢ <span class="pho alt">teɪᵊl</span><span class="speak-word-inline" data-audio-us-male="/audios/tale-us-male.mp3" data-audio-us-female="/audios/tale-us-female.mp3"></span>
> * *trail* <span class="pho alt">treɪl</span> ⭢ <span class="pho alt">treɪᵊl</span><span class="speak-word-inline" data-audio-us-male="/audios/trail-us-male.mp3" data-audio-us-female="/audios/trail-us-female.mp3"></span>
> * *drill* <span class="pho alt">drɪl</span> ⭢ <span class="pho alt">drɪᵊl</span><span class="speak-word-inline" data-audio-us-male="/audios/drill-us-male.mp3" data-audio-us-female="/audios/drill-us-female.mp3"></span>

> [!Note]
> 
> В <span class="pho alt">ʌl</span> вставного <span class="pho">ᵊ</span> нет, потому что <span class="pho">ʌ</span> и <span class="pho">ə</span> и так очень близки. Например, *ultimate* <span class="pho alt">ˈʌltɪmət</span><span class="speak-word-inline" data-audio-us-male="/audios/ultimate-us-male.mp3" data-audio-us-female="/audios/ultimate-us-female.mp3"></span> или *result* <span class="pho alt">rɪˈzəlt</span><span class="speak-word-inline" data-audio-us-male="/audios/result-us-male.mp3" data-audio-us-female="/audios/result-us-female.mp3"></span>. Кроме того, в живой речи следите за <span class="pho alt">iːl</span>. Например, у *reveal* в словаре транскрипция <span class="pho alt">rɪˈviːl</span>, но читается оно действительно как <span class="pho alt">rɪˈviːᵊl</span><span class="speak-word-inline" data-audio-us-male="/audios/reveal-us-male.mp3" data-audio-us-female="/audios/reveal-us-female.mp3"></span>, со вставным <span class="pho">ᵊ</span>; а *revealing* читается как <span class="pho alt">rɪˈviːlɪŋ</span><span class="speak-word-inline" data-audio-us-male="/audios/revealing-us-male.mp3" data-audio-us-female="/audios/revealing-us-female.mp3"></span>, без него — вероятно, потому, что <span class="pho">l</span> перешёл дальше и вместе с <span class="pho">ɪŋ</span> образовал третий слог <span class="pho alt">lɪŋ</span>…

В лингвистике у <span class="pho">l</span> есть особое название — **слоговой согласный** (<span class="pho">l</span>, <span class="pho">r</span>, <span class="pho">m</span>, <span class="pho">n</span> — все слоговые согласные): если его движение выполнено полностью, перед ним само собой появляется лёгкий гласный призвук <span class="pho">ᵊ</span>. Например, *little* <span class="pho alt">ˈlɪtl̩</span><span class="speak-word-inline" data-audio-us-male="/audios/little-us-male.mp3" data-audio-us-female="/audios/little-us-female.mp3"></span>: точка под <span class="pho">l̩</span> означает, что здесь <span class="pho">l̩</span> — **слоговой согласный**, равный <span class="pho alt">ᵊl</span>… Конечно, многие словари попросту пишут <span class="pho alt">ˈlɪtᵊl</span> или <span class="pho alt">ˈlɪtəl</span>. В «Кембриджском словаре английского произношения» знака слогового согласного нет, и <span class="pho">ᵊ</span> с <span class="pho">ə</span> не различаются: там <span class="pho alt">ˈlɪt̬əl</span> (заметьте ещё: <span class="pho">t</span> стоит между двумя гласными и стал одноударным <span class="pho">t̬</span>).

## 3.2.12.4. Сравнение положений кончика языка

Сравните, чем различается **начальное положение кончика языка** у следующих согласных:

![articulator-tongue-tip-positions](/images/articulator-tongue-tip-positions.svg)

> * у <span class="pho">t/d</span> кончик языка прижат к передней части альвеол ③;
> * у <span class="pho">s/z</span> он чуть впереди, чем у <span class="pho">t/d</span>: подходит к месту, где зубы переходят в дёсны, но не касается его ②;
> * у <span class="pho">θ/ð</span> ещё чуть впереди, чем у <span class="pho">s/z</span>: прижат к зубам или чуть выдвинут за них ①;
> * у <span class="pho">ʃ/ʒ</span>, как у <span class="pho">t/d</span>, у альвеол, но не касается их ③;
> * у <span class="pho">tʃ/dʒ</span>, как у <span class="pho">t/d</span>, прижат к альвеолам ③;
> * у <span class="pho">l</span>, как у <span class="pho">t/d</span>, прижат к альвеолам ③;
> * у <span class="pho">r</span> ещё чуть дальше назад, чем у <span class="pho">ʃ/ʒ</span>, за альвеолами ④…

| :---------------------: | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|            ①            | <span class="pho">θ</span>, <span class="pho">ð</span>                                                                                                                                                                                                         |
|            ②            | <span class="pho">s</span>, <span class="pho">z</span>                                                                                                                                                                                                         |
|            ③            | <span class="pho">t</span>, <span class="pho">d</span>, <span class="pho">l</span>, <span class="pho">ʃ</span>, <span class="pho">ʒ</span>, <span class="pho">tʃ</span>, <span class="pho">dʒ</span>, <span class="pho">tr</span>, <span class="pho">dr</span> |
|            ④            | <span class="pho">r</span>                                                                                                                                                                                                                                     |
