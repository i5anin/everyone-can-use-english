# 3.1.3. <span class="pho">ɪ</span>/<span class="pho">i</span>/<span class="pho">iː</span>/<span class="pho">ɪr</span>

В американском английском у <span class="pho">i</span> *3* варианта: краткая <span class="pho">ɪ</span>, долгая <span class="pho">iː</span> и лёгкая <span class="pho">i</span>. Из них у <span class="pho">i</span> и <span class="pho">iː</span> рот раскрыт меньше всего, а у <span class="pho">ɪ</span> — сравнительно шире.

## 3.1.3.2. Краткая гласная <span class="pho">ɪ</span>

Краткая <span class="pho">ɪ</span> — вовсе не просто укороченная долгая <span class="pho">iː</span>: это скорее звук между <span class="pho">e</span> и <span class="pho">i</span>. На слух она очень похожа на укороченную <span class="pho">eɪ</span>, а по форме губ <span class="pho">ɪ</span> ближе к <span class="pho">e</span>. Не путайте её с русским «ы» и с русским «и»: она открытее и расслабленнее обоих.

![vowels-mouth-shape-ɪ-i](/images/vowels-mouth-shape-ɪ-i.svg)

Вслушайтесь в эти слова:

> * *bit* <span class="pho alt">bɪt</span><span class="speak-word-inline" data-audio-us-male="/audios/bit-us-male.mp3" data-audio-us-female="/audios/bit-us-female.mp3"></span>
> * *sit* <span class="pho alt">sɪt</span><span class="speak-word-inline" data-audio-us-male="/audios/sit-us-male.mp3" data-audio-us-female="/audios/sit-us-female.mp3"></span>
> * *hill* <span class="pho alt">hɪl</span><span class="speak-word-inline" data-audio-us-male="/audios/hill-us-male.mp3" data-audio-us-female="/audios/hill-us-female.mp3"></span>

## 3.1.3.3. Долгая гласная <span class="pho">iː</span>

<span class="pho">iː</span> — вовсе не просто удлинённая краткая <span class="pho">ɪ</span>: в ней нет призвука <span class="pho">eɪ</span>, а губы растянуты площе, чем при <span class="pho">ɪ</span>.

Сравним ещё раз:

> * *bit* <span class="pho alt">bɪt</span><span class="speak-word-inline" data-audio-us-male="/audios/bit-us-male.mp3" data-audio-us-female="/audios/bit-us-female.mp3"></span> ⭤ *beat* <span class="pho alt">bi:t</span><span class="speak-word-inline" data-audio-us-male="/audios/beat-us-male.mp3" data-audio-us-female="/audios/beat-us-female.mp3"></span>
> * *sit* <span class="pho alt">sɪt</span><span class="speak-word-inline" data-audio-us-male="/audios/sit-us-male.mp3" data-audio-us-female="/audios/sit-us-female.mp3"></span> ⭤ *seat* <span class="pho alt">si:t</span><span class="speak-word-inline" data-audio-us-male="/audios/seat-us-male.mp3" data-audio-us-female="/audios/seat-us-female.mp3"></span>
> * *hill* <span class="pho alt">hɪl</span><span class="speak-word-inline" data-audio-us-male="/audios/hill-us-male.mp3" data-audio-us-female="/audios/hill-us-female.mp3"></span> ⭤ *heal* <span class="pho alt">hi:l</span><span class="speak-word-inline" data-audio-us-male="/audios/heal-us-male.mp3" data-audio-us-female="/audios/heal-us-female.mp3"></span>

## 3.1.3.4. Лёгкая гласная <span class="pho">i</span>

У звука <span class="pho">i</span> на деле есть ещё полудолгий вариант, чаще всего в конце слова: он скорее похож на укороченную долгую <span class="pho">iː</span> и является **лёгкой гласной**, потому что встречается только в **безударных слогах**.

Например, *city* <span class="pho alt">ˈsɪt̬.i</span><span class="speak-word-inline" data-audio-us-male="/audios/city-us-male.mp3" data-audio-us-female="/audios/city-us-female.mp3"></span><span class="speak-word-inline" data-audio-uk-male="/audios/city-uk-male.mp3" data-audio-uk-female="/audios/city-uk-female.mp3"></span> или *responsibility* <span class="pho alt">rɪˌspɑːn·səˈbɪl·ə·t̬i</span><span class="speak-word-inline" data-audio-us-male="/audios/responsibility-us-male.mp3" data-audio-us-female="/audios/responsibility-us-female.mp3"></span><span class="speak-word-inline" data-audio-uk-male="/audios/responsibility-uk-male.mp3" data-audio-uk-female="/audios/responsibility-uk-female.mp3"></span> — здесь британское и американское произношение совпадают.

Заметьте: это, вероятно, расходится с тем, чему учили в школе, — в основном потому, что учебники годами не обновлялись. Даже «Кембриджский словарь английского произношения» лишь в *13*-м издании везде заменил конечную <span class="pho">ɪ</span> на <span class="pho">i</span> (у неё даже есть особое название — *happy i*). К тому же «живое произношение» в большинстве электронных словарей появилось лишь в последние десять с небольшим лет.

## 3.1.3.5. Гласная с «r»-окраской <span class="pho">ɪr</span>

Особенно заметьте: <span class="pho">ɪr</span> — на деле вариант <span class="pho">i</span> с «r»-окраской, а не <span class="pho">ɪ</span>.

<span class="pho">ɪr</span> соответствует британскому <span class="pho">ɪə</span> и по сути является дифтонгом с «r»-окраской — его можно понимать как <span class="pho">iᵊr</span> или <span class="pho">iɚ</span>, например *ear* <span class="pho alt">ɪr</span> <span class="speak-word-inline" data-audio-us-male="/audios/ear-us-male.mp3" data-audio-us-female="/audios/ear-us-female.mp3"></span>… Но осторожно: не всякая конечная <span class="pho">ə</span> получает «r»-окраску — например, в *idea* <span class="pho alt">aɪˈdiː.ə</span> <span class="speak-word-inline" data-audio-us-male="/audios/idea-us-male.mp3" data-audio-us-female="/audios/idea-us-female.mp3"></span> конечная <span class="pho">ə</span> без неё.
