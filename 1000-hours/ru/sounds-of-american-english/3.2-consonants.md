# 3.2. Согласные (Consonants)

Во всех языках Земли **согласные** в живой речи не существуют сами по себе. Отдельная **гласная** может образовать **слог**, а может и составить слово или выразить смысл. Например, *ah* <span class="pho alt">ɑː</span><span class="speak-word-inline" data-audio-us-male="/audios/us_phonetics_sound_father_2023feb.mp3"></span>, *oh* <span class="pho alt">oʊ</span><span class="speak-word-inline" data-audio-us-male="/audios/us_phonetics_sound_nose_2023feb.mp3"></span> или *Uh-Oh* <span class="pho alt">ˈʌ.oʊ</span><span class="speak-word-inline" data-audio-us-female="/audios/Uh-Oh.mp3"></span>[^1]. Но подавляющее большинство **согласных** образуют **слог**, только опираясь на **гласную**, и отдельный согласный смысла не несёт.

По тому, колеблются ли при произнесении **голосовые связки**, согласные делятся на глухие (voiceless consonants) и звонкие (voiced consonants). При глухих колеблется только воздух, без участия связок, а при звонких колебание воздуха сопровождается колебанием связок. Например, <span class="pho">s</span> — глухой, <span class="pho">z</span> — звонкий.

|                     | Согласные (consonants) |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Глухие (voiceless) | <span class="pho">p</span>, <span class="pho">t</span>, <span class="pho">k</span>, <span class="pho">f</span>, <span class="pho">s</span>, <span class="pho">θ</span>, <span class="pho">ʃ</span>, <span class="pho">h</span>, <span class="pho">tʃ</span>, <span class="pho">tr</span>, <span class="pho">ts</span>                                                                                                                 |
| Звонкие (voiced)    | <span class="pho">b</span>, <span class="pho">d</span>, <span class="pho">g</span>, <span class="pho">v</span>, <span class="pho">z</span>, <span class="pho">ð</span>, <span class="pho">ʒ</span>, <span class="pho">r</span>, <span class="pho">dʒ</span>, <span class="pho">dr</span>, <span class="pho">dz</span>, <span class="pho">m</span>, <span class="pho">n</span>, <span class="pho">ŋ</span>, <span class="pho">l</span> |

Заметьте: согласные <span class="pho">w</span> и <span class="pho">j</span> называют **полугласными**: по участию связок их не классифицируют.

Ещё одно деление согласных — по способу и месту образования **воздушной струи** во рту.

| Способ образования (Airflow) | Глухой или звонкий (Voiced or not) | Согласные (Consonants) |
| ----------------------- | ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Взрывные (Plosive)       | глухие                    | <span class="pho">p</span>, <span class="pho">t</span>, <span class="pho">k</span>                                                         |
|                         | звонкие                    | <span class="pho">b</span>, <span class="pho">d</span>, <span class="pho">g</span>                                                         |
| Щелевые (Fricative)     | глухие                    | <span class="pho">f</span>, <span class="pho">s</span>, <span class="pho">θ</span>, <span class="pho">ʃ</span>, <span class="pho">h</span> |
|                         | звонкие                    | <span class="pho">v</span>, <span class="pho">z</span>, <span class="pho">ð</span>, <span class="pho">ʒ</span>                             |
| Аффрикаты (Affricate)     | глухие                    | <span class="pho">tʃ</span>, <span class="pho">tr</span>, <span class="pho">ts</span>                                                      |
|                         | звонкие                    | <span class="pho">dʒ</span>, <span class="pho">dr</span>, <span class="pho">dz</span>                                                      |
| Носовые (Nasal)           | звонкие                    | <span class="pho">m</span>, <span class="pho">n</span>, <span class="pho">ŋ</span>                                                         |
| Боковые и плавные (Lateral)       | звонкие                    | <span class="pho">l</span>, <span class="pho">r</span>                                                                                     |
| Полугласные (Semivowel)     |                           | <span class="pho">j</span>, <span class="pho">w</span>                                                                                     |

Начинающему **незачем стараться запомнить эти разряды и термины** — разве что в будущем найдутся лишние время и силы. Эти лингвистические понятия никак не мешают учиться. Нужно лишь понимать, **на чём** основано деление: **колеблются ли связки** и **как и где образуется воздушная струя**.

Ещё заметьте: *4* согласных — <span class="pho">l</span>, <span class="pho">m</span>, <span class="pho">n</span> и уже не раз встречавшийся <span class="pho">r</span> — называют «**слоговыми согласными**», потому что они несут в себе призвук <span class="pho">ə</span>. Например, *bottle* <span class="pho alt">ˈbɑːtl</span>, *bottom* <span class="pho alt">ˈbɑːtm</span>, *button* <span class="pho alt">ˈbʌtn</span>. Некоторые словари пишут <span class="pho">ᵊ</span>, например:
*bottle* <span class="pho alt">ˈbɑːtᵊl</span>, *bottom* <span class="pho alt">ˈbɑːtᵊm</span>, *button* <span class="pho alt">ˈbʌtᵊn</span>. А «Кембриджский словарь английского произношения» пишет так: *bottle* <span class="pho alt">ˈbɑːt̬əl</span>, *bottom* <span class="pho alt">ˈbɑːt̬əm</span>, *button* <span class="pho alt">ˈbʌtən</span>…

Особенно важно: при произнесении согласных очень важно **начальное положение кончика языка**.
