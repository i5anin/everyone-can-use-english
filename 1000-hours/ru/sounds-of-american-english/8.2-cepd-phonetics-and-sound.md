# 8.2. Как получить транскрипцию CEPD

На GitHub есть открытый репозиторий с базой «Кембриджского словаря английского произношения» в формате json:

> https://github.com/zelic91/camdict

Скачайте из этого репозитория [cam_dict.refined.json](https://github.com/zelic91/camdict/raw/main/cam_dict.refined.json) и сохраните где-нибудь у себя.

Я написал сценарий (workflow) для Alfred на встроенном в macOS *python3* (`/usr/bin/python3`): по ключевому слову он запускает скрипт на Python, который ищет транскрипцию слова (и даже целой фразы) в «Кембриджском словаре английского произношения» (CEPD).

> [CEPD-phonetic-transcription.alfredworkflow](https://1000h.org/alfred-workflows/CEPD-phonetic-transcription.alfredworkflow)

Скачав этот файл, импортируйте его в Alfred.

Перед использованием учтите:

> * поправьте путь к файлу `cam_dict.refined.json` в каждом скрипте на Python.

Ключевые слова этого сценария:

> * `cams`: найти транскрипцию (американское произношение)
> * `camk`: найти транскрипцию (британское произношение)
> * `camsd`: открыть в браузере живую запись произношения CEPD (американское)
> * `camkd`: открыть в браузере живую запись произношения CEPD (британское)
> * `camw`: открыть в браузере страницу поиска CEPD
> * `ipa`: вернуть транскрипцию из словаря произношения CMU (Университета Карнеги — Меллона)

Вот скрипт на Python из сценария поиска транскрипции (ключевое слово `cams`):

```python
#
# NOTE: Python 2 is deprecated in macOS, and has been removed from macOS 12.3+
#
import sys
import json

# Предполагаем, что база JSON лежит в файле: загружаем данные из него
# Если данные JSON в памяти или в другом формате, эту часть кода, возможно, придётся изменить
def load_json_database(file_path):
    records = []
    with open(file_path, 'r') as file:
        for line in file:
            try:
                record = json.loads(line)
                records.append(record)
            except json.JSONDecodeError as e:
                print(f"Error parsing JSON: {e}")
    return records

# Ищем word в базе JSON
def search_in_json_database(database, search_word, region):
    for record in database:
        # Проверяем, совпадает ли поле word
        if record.get('word') == search_word:
            # Нашли совпадение — берём сведения об американском произношении
            pos_items = record.get('pos_items', [])
            for pos_item in pos_items:
                pronunciations = pos_item.get('pronunciations', [])
                for pronunciation in pronunciations:
                    if pronunciation.get('region') == region:
                        # Нашли американское произношение — возвращаем сведения
                        return {
                            'pronunciation': pronunciation.get('pronunciation'),
                            'audio': pronunciation.get('audio')
                        }
    # Если подходящего поля word не нашлось, возвращаем 'not exist'
    return 'not exist'

# Путь к файлу cam_dict.refined.json
json_db_file_path = '/Users/joker/github/camdict/cam_dict.refined.json'

# Слово для поиска
search_word = sys.argv[1]

region = "us"

json_database = load_json_database(json_db_file_path)

# replace punctuations in text with space
punctuations = ",.?!;"
for p in punctuations:
    search_word = search_word.replace(p, " ")
words = [word for word in search_word.split() if word.strip() != '']

phonetics = []

for w in words:
  # Ищем и получаем результат
  w = w.strip().lower()

  if w[-1] in punctuations:
    w = w.rstrip(",.?!;")
  result = search_in_json_database(json_database, w, region)

  if result == 'not exist':
    phonetics.append(w+"*")
  else:
    phonetics.append(result['pronunciation'])

returnvalue = ''
for p in phonetics:
  returnvalue += p + ' '

sys.stdout.write(returnvalue.strip())
```
