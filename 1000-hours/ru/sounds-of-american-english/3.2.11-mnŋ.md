## 3.2.11.2. Без <span class="pho">ʊ</span>

<span class="pho">m</span> и <span class="pho">n</span> в начале слога ни у кого трудностей не вызывают. Особенно <span class="pho">m</span>… ведь это, пожалуй, первый согласный, которому учится человек; а <span class="pho">ɑ</span> всегда первая гласная. Потому все и зовут мать <span class="pho">mɑ</span><span class="speak-word-inline" data-audio-us-male="/audios/ma-us-male.mp3" data-audio-us-female="/audios/ma-us-female.mp3"></span>.

<span class="pho">ŋ</span> после гласных тоже ни для кого не труден: в английском чаще всего это лишь <span class="pho">ɪŋ</span>… Но говорящим по-русски стоит помнить: <span class="pho">ŋ</span> — это не «нг» и не «н», а один звук, при котором задняя часть языка смыкается с мягким нёбом, а воздух идёт через нос; на конце *-ing* не должно слышаться «г».

Трудность — <span class="pho">m</span> в конце слога. Многие невольно добавляют звук <span class="pho">ʊ</span> — это следствие лишнего движения губ. Например, читают *room* <span class="pho alt">ruːm</span><span class="speak-word-inline" data-audio-us-male="/audios/room-us-male.mp3" data-audio-us-female="/audios/room-us-female.mp3"></span> как <span class="pho alt">ruːmʊ</span>.

## 3.2.11.3. Изменения звука

Перед <span class="pho">f/v</span> звуки <span class="pho">m/n</span> меняются: ведь при <span class="pho">f/v</span> верхние зубы касаются нижней губы.

> * <span class="pho">m + f/v</span> = <span class="pho">n + f/v</span>, *comfort* <span class="pho alt">ˈkəmfərt</span> → <span class="pho alt">ˈkənfərt</span><span class="speak-word-inline" data-audio-us-male="/audios/comfort-us-male.mp3" data-audio-us-female="/audios/comfort-us-female.mp3"></span>
> * <span class="pho">n + f/v</span> = <span class="pho">ŋ + f/v</span>, *conversation* <span class="pho alt">ˌkɑnvərˈseɪʃən</span> → <span class="pho alt">ˌkɑŋvərˈseɪʃən</span><span class="speak-word-inline" data-audio-us-male="/audios/conversation-us-male.mp3" data-audio-us-female="/audios/conversation-us-female.mp3"></span>

## 3.2.11.4. Вставной звук <span class="pho">ᵊ</span>

Когда <span class="pho">æ</span> стоит перед <span class="pho">m</span>, некоторые носители языка вставляют <span class="pho">ᵊ</span>: например, Sam <span class="pho alt">sæm</span><span class="speak-word-inline" data-audio-us-male="/audios/sam-us-male.mp3" data-audio-us-female="/audios/sam-us-female.mp3"></span> они читают как <span class="pho alt">sæᵊm</span>. В этом есть смысл: <span class="pho">m</span> действительно слоговой согласный. Например, *chasm* <span class="pho alt">ˈkæzm̩</span><span class="speak-word-inline" data-audio-us-male="/audios/chasm-us-male.mp3" data-audio-us-female="/audios/chasm-us-female.mp3"></span> равно <span class="pho alt">ˈkæzᵊm</span>, *prism* <span class="pho alt">ˈprɪzm̩</span><span class="speak-word-inline" data-audio-us-male="/audios/prism-us-male.mp3" data-audio-us-female="/audios/prism-us-female.mp3"></span> — <span class="pho alt">ˈprɪzᵊm</span>.
