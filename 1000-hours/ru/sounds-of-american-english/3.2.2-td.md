# 3.2.2. <span class="pho">t</span>/<span class="pho">d</span>

<span class="pho">t</span> — глухой, <span class="pho">d</span> — звонкий. <span class="pho">d</span> сравнительно прост, а вот <span class="pho">t</span>, пожалуй, самый сложный звук американского английского и потому один из согласных, которые больше всего нужно упражнять отдельно.

## 3.2.2.2. Начальное положение кончика языка

Эти два согласных есть во всех языках, но главное в английских <span class="pho">t/d</span> — **начальное положение кончика языка**: он упирается в **альвеолы** (*alveolar ridge*), то есть в положение ③, а не прижимается к зубам.

В русском языке, как и в китайском, при <span class="pho">t/d</span> кончик языка прижат к зубам. Скажите по-русски «тётя Даша» — и почувствуете, где язык.

Поэтому для нас это довольно трудно исправимая привычка: кончик языка невольно, по привычке родного языка, прижимается к зубам (положение ①), а не к альвеолам (положение ③). Новую привычку можно создать только большим и плотным объёмом упражнений. Классическое слово для упражнения — *student* <span class="pho alt">ˈstuː.dənt</span><span class="speak-word-inline" data-audio-us-male="/audios/student-us-male.mp3" data-audio-us-female="/audios/student-us-female.mp3"></span>.

## 3.2.2.3. Не <span class="pho">tə/də</span>

Особо напомним: хотя в «Кембриджском словаре английского произношения» образцы <span class="pho">t/d</span> произнесены как <span class="pho">tə</span><span class="speak-word-inline" data-audio-us-male="/audios/us_phonetics_sound_town_2023feb.mp3"></span> и <span class="pho">də</span><span class="speak-word-inline" data-audio-us-male="/audios/us_phonetics_sound_day_2023feb_001.mp3"></span>, в живой речи эти звуки так не звучат.

Как и <span class="pho">p/b</span>, <span class="pho">t/d</span> в живой речи сами собой несут очень лёгкий <span class="pho">ɤ</span>, а не <span class="pho">ə</span>. По привычке родного языка мы склонны произносить <span class="pho">t(ɤ)</span> как «тэ» или «ты», а <span class="pho">d(ɤ)</span> — как «дэ» или «ды». И здесь нужно выработать новую привычку.

## 3.2.2.4. Варианты <span class="pho">t</span>

Звук <span class="pho">t</span> — к тому же один из самых частых — пожалуй, самый сложный из согласных американского английского. Обычным образом t произносится, только когда стоит в начале ударного слога, например *take* <span class="pho alt">teɪk</span><span class="speak-word-inline" data-audio-us-male="/audios/take-us-male.mp3" data-audio-us-female="/audios/take-us-female.mp3"></span>.

Кроме обычного <span class="pho">t</span> у него много вариантов (*allophone*): одноударный <span class="pho">t̬</span>, смычка без взрыва <span class="pho">t̚</span>, выпадающий или необязательный <span class="pho">ᵗ</span>, а также гортанная смычка <span class="pho">ʔ</span>, которую многие без объяснения совсем не замечают.

### 3.2.2.4.1. Одноударный <span class="pho">t̬</span>

<span class="pho">t</span> между двумя гласными превращается в похожий на <span class="pho">d</span> одноударный <span class="pho">t̬</span> — кончик языка один раз легко ударяет по альвеолам, например *water* <span class="pho alt">ˈwɑːt̬ɚ</span><span class="speak-word-inline" data-audio-us-male="/audios/water-us-male.mp3" data-audio-us-female="/audios/water-us-female.mp3"></span>. Американская транскрипция «Кембриджского словаря английского произношения» нарочно улучшена: в ней отмечен одноударный <span class="pho">t̬</span>. В большинстве словарей этого нет.

### 3.2.2.4.2. Смычка без взрыва <span class="pho">t̚</span>

<span class="pho">t</span> в конце слога иногда только обозначается движением кончика языка, а звука нет: язык упирается в альвеолы, но воздух не выпускается. Например, *but* <span class="pho alt">bʌt̚</span><span class="speak-word-inline" data-audio-us-male="/audios/but-stop-us-male.mp3" data-audio-us-female="/audios/but-stop-us-female.mp3"></span>.

### 3.2.2.4.3. Выпадающий или необязательный <span class="pho">ᵗ</span>

В <span class="pho">nt</span> в конце слога <span class="pho">t</span> может выпадать, например *winter* <span class="pho alt">ˈwɪnᵗɚ</span><span class="speak-word-inline" data-audio-us-male="/audios/winter-optional-us-male.mp3" data-audio-us-female="/audios/winter-optional-us-female.mp3"></span>; впрочем, прочесть <span class="pho alt">ˈwɪntɚ</span><span class="speak-word-inline" data-audio-us-male="/audios/winter-us-male.mp3" data-audio-us-female="/audios/winter-us-female.mp3"></span> тоже не ошибка…[^1]

### 3.2.2.4.4. Гортанная смычка <span class="pho">ʔ</span>

Гортанная смычка <span class="pho">ʔ</span> — ещё один знак Международного фонетического алфавита, которого нет в английских системах транскрипции.

Гортанная смычка <span class="pho">ʔ</span> похожа на смычку без взрыва у звука <span class="pho">g</span> — <span class="pho">g̚</span>: как при произнесении big со смычкой, задняя часть спинки языка поднимается к мягкому нёбу и не отходит, воздух не выходит, и звук будто на миг застревает… Послушайте несколько раз *Uh-Oh!* <span class="pho alt">ʌʔoʊ</span><span class="speak-word-inline" data-audio-us-female="/audios/Uh-Oh.mp3"></span> — и станет понятно. Похожая заминка бывает и в русском «не-а».

<span class="pho">t</span> перед <span class="pho">m/n/l</span> может превращаться в гортанную смычку <span class="pho">ʔ</span>, например *utmost* <span class="pho alt">ˈʌʔˌmoʊst</span><span class="speak-word-inline" data-audio-us-male="/audios/utmost-us-male.mp3" data-audio-us-female="/audios/utmost-us-female.mp3"></span>, *fitness* <span class="pho alt">ˈfɪʔnəs</span><span class="speak-word-inline" data-audio-us-male="/audios/fitness-us-male.mp3" data-audio-us-female="/audios/fitness-us-female.mp3"></span>, *witness* <span class="pho alt">ˈwɪʔnəs</span><span class="speak-word-inline" data-audio-us-male="/audios/witness-us-male.mp3" data-audio-us-female="/audios/witness-us-female.mp3"></span> или *fruitless* <span class="pho alt">ˈfruːʔləs</span><span class="speak-word-inline" data-audio-us-male="/audios/fruitless-us-male.mp3" data-audio-us-female="/audios/fruitless-us-female.mp3"></span>. Разумеется, все словари одинаково пишут <span class="pho">t</span>, а не <span class="pho">ʔ</span>.

### 3.2.2.4.5. Озвончение <span class="pho">t</span>

<span class="pho">t</span> после <span class="pho">s</span> **озвончается** и звучит как <span class="pho">d</span>, хотя в словарной транскрипции остаётся <span class="pho">t</span>. Например, у *student* в словаре по-прежнему <span class="pho alt">ˈstuː.dənt</span>, а звучит <span class="pho alt">ˈsduː.dənt</span><span class="speak-word-inline" data-audio-us-male="/audios/student-us-male.mp3" data-audio-us-female="/audios/student-us-female.mp3"></span>
.

## 3.2.2.5. Оглушение <span class="pho">d</span>

<span class="pho">t</span> может **озвончаться**… а <span class="pho">d</span>, наоборот, может **оглушаться**. Например, *ed* иногда читается не <span class="pho alt">ɪd</span>: после глухих <span class="pho">p</span>, <span class="pho">k</span>, <span class="pho">f</span>, <span class="pho">s</span>, <span class="pho">ʃ</span>, <span class="pho">tʃ</span>, <span class="pho">θ</span> оно читается как <span class="pho alt">t</span>. Например, *hoped* <span class="pho alt">hoʊpt</span> <span class="speak-word-inline" data-audio-us-male="/audios/hoped-us-male.mp3" data-audio-us-female="/audios/hoped-us-female.mp3"></span>, *laughed* <span class="pho alt">læft</span> <span class="speak-word-inline" data-audio-us-male="/audios/laughed-us-male.mp3" data-audio-us-female="/audios/laughed-us-female.mp3"></span>, *liked* <span class="pho alt">laɪkt</span> <span class="speak-word-inline" data-audio-us-male="/audios/liked-us-male.mp3" data-audio-us-female="/audios/liked-us-female.mp3"></span>, *watched* <span class="pho alt">wɑːtʃt</span> <span class="speak-word-inline" data-audio-us-male="/audios/watched-us-male.mp3" data-audio-us-female="/audios/watched-us-female.mp3"></span>.
